# Первый запуск MiniFuse 2 for Linux

Для установки через `apt` или `pacman` см. [пакеты и переход с ручной установки](packages.md).

Приложение рассчитано на Arturia MiniFuse 2. Проверенная конфигурация —
48 кГц с частотой и буфером Auto. В версии 0.1.1 настольный интерфейс доступен на русском и английском.

## Установка

Скачай архив из [GitHub Releases](https://github.com/Potato83/MiniFuze-for-Linux/releases).
Сборка `ubuntu-24.04-x86_64` предназначена для Ubuntu 24.04 x86_64. Для другой
системы используй исходники и зависимости из [README](../README.md#build).
Проверка Ubuntu в CI охватывает сборку и программные тесты; физическая карта
проверялась на CachyOS.

На Ubuntu 24.04 установи зависимости готовой сборки:

```sh
sudo apt install libgtk-4-1 libsoup-3.0-0 libjson-c5 libmicrohttpd12t64 libssl3t64 pipewire-bin wireplumber
```

Положи архив и его `.sha256` в одну папку, затем выполни:

```sh
sha256sum -c minifuze2-0.1.0-ubuntu-24.04-x86_64.tar.gz.sha256
tar -xzf minifuze2-0.1.0-ubuntu-24.04-x86_64.tar.gz
cd minifuze2-0.1.0
sha256sum -c SHA256SUMS
bash tools/install_desktop.sh
```

Установщик приложения запускается **без sudo**. Если приложение уже установлено
этим скриптом, закрой окно и используй `bash tools/install_desktop.sh --update`.
Обновление кратко перезапустит микшер, сохранив настройки и пресеты.

Стандартный USB-звук обслуживает ALSA. Для кнопок +48V/INST/Mono, аппаратного
loopback и индикаторов входов нужен модуль `minifuze2_ctl` версии 0.2.0.
Его установка и требования к заголовкам ядра описаны отдельно в
[инструкции](installation.md#kernel-control-endpoint).

## Музыка и наушники

1. Подключи MiniFuse и наушники к PHONES. Поставь небольшую громкость PHONES.
2. Открой **MiniFuse 2 for Linux** из меню приложений. Выбери свою карту и подключи её к микшеру.
3. Оставь частоту и буфер в **Auto**. Для программного микширования поверни ручку **MIX к USB**.
4. В настройках звука проигрывателя или системы направь музыку в **MiniFuse Main 1/2**.
5. Открой микс Main. Полоса Main должна быть слышна; проверь её Mute/Solo, общий Mute и положение фейдеров.

Закрытие окна оставляет службу и звук работающими. Тема меняется в
«Настройки → Оформление» и не входит в звуковой пресет.

## Микрофон и запись

Подключи XLR-микрофон ко входу 1 или 2, настрой GAIN на карте и следи за
клиппингом. Включай +48V только если микрофону требуется фантомное питание;
оно общее для двух входов. Выбор пресета не включает +48V автоматически.

Для записи в DAW выбери **MiniFuse Input 1/2**. Это пара входов: при микрофоне
во входе 1 выбери левый канал как **моно-вход дорожки**. Для программного
мониторинга сними Mute нужного аналогового входа в Main. Для прямого мониторинга
используй ручку MIX на карте; Direct Mono распределяет один вход на оба уха.

## Если звука или управления нет

- Проверь карту, выбранный выход проигрывателя, ручки PHONES/MIX и Mute/Solo.
- Если звук вернулся после смены USB-порта, а аппаратные кнопки не работают, проверь выбор карты модулем по серийному номеру: [объяснение](installation.md#kernel-control-endpoint).
- После перезапуска всей службы PipeWire DAW может потребовать повторного подключения своего аудиодвижка. Проект сохраняй до такой проверки.
- Для сообщения об ошибке укажи версию приложения, систему, ядро, PipeWire, прошивку карты и шаги воспроизведения. Удаляй серийные номера и личные пути из журналов.

Обновление прошивки и передача по MIDI DIN в приложении не поддерживаются.
Подробные результаты проверок находятся в [отчёте](hardware-validation.md).
